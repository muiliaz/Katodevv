# 13 — Возврат линтера

**P2** · аудиты tech-health TH-005, cicd (шаг 5) · 2026-08-07

## Проблема

Побочный эффект нашей же миграции: вместе с `react-scripts` ушёл встроенный ESLint, и проект какое-то
время жил **вообще без линтера** — то есть по этому пункту стал хуже, чем был до начала работы.

## Два решения

**Без Prettier.** TH-005 просит и форматирование, но оно перепишет почти каждый файл и утопит
содержательный дифф. Отдельное решение и отдельный коммит.

**Не «recommended» набор правил.** `eslint-plugin-react-hooks` v6 тянет в него правила React
Compiler. На первом прогоне — **15 ошибок, и ни одна не баг**: они сообщают, что код нельзя
автоматически оптимизировать. Принять их значит переписывать компоненты вокруг GSAP и Three.js.
Оставили два классических правила, которые и применял CRA.

## Что линтер нашёл сразу

**TH-006 — тихие `catch`.** Аудит просил «сохранить fallback, но добавить комментарий о причине».

| Где | Почему молчит |
|---|---|
| `ChatWidget.jsx` | `sessionStorage` падает в приватном режиме и при переполнении квоты; пустой диалог — правильный исход |
| `BlackHole.jsx` | выполняется **каждый кадр**; логирование засорило бы консоль 60 раз в секунду ради косметической виньетки |

Оба несут объяснение в коде — TH-006 закрыт.

**TH-005 — подавления.** Из 13 подавлений `exhaustive-deps` **восемь больше ничего не подавляют**.
Убраны. Осталось 5 живых, видимых как предупреждения.

## Проверка

`npm run lint` чист. Правила живые — временный компонент с двумя нарушениями:

```
React Hook "useState" is called conditionally   react-hooks/rules-of-hooks
'unusedVar' is assigned a value but never used  no-unused-vars
```

Шаг `Lint` стоит в CI **до** тестов: он идёт секунды, незачем ждать полного набора ради
неиспользуемой переменной.

## Осталось

Форматтер, `.editorconfig`, 5 живых подавлений (требуют понимания конкретных таймлайнов).
