# Аудит неиспользуемого кода

## Краткое резюме

- Понимание живого поведения репозитория умеренно замедляет ограниченный, но заметный кластер остатков отключённой секции Portfolio; итоговая оценка — **68 из 100** (`warn`).
- Подтверждены три кандидата на очистку: кластер Portfolio, неимпортируемый `useLenis` и пустой `Loader.css`. `web-vitals` с уверенностью 82% вероятно не используется.
- Объявленные CI, Netlify, переменные Telegram и package scripts имеют потребителей; общей проблемы процессной зрелости по ним не выявлено.
- Главный следующий шаг — решить, вернуть ли Portfolio в `/web` или удалить его остатки согласованным кластером, не затронув `PORTFOLIO_DATA.bots.items`, используемый страницей Bots.

Проверены граф импортов от `frontend/src/index.js`, маршруты в `frontend/src/app/App.js`, страницы `/`, `/web`, `/bots`, `/apps`, Netlify-функции, CSS, локализация, public assets, зависимости, package scripts, CI и `netlify.toml`. Отдельно проверены защищённые внешними соглашениями поверхности: Netlify entry points, `_redirects`, `robots.txt`, `sitemap.xml` и файл подтверждения Yandex.

Проектного `GUARD.md` или `ENJI_GUARD.md` нет; дополнительных указаний владельца, меняющих область или классификацию, не применялось. Внешний трафик, телеметрия и прямые запросы к public assets не проверялись.

Уверенность высокая для исходного кода и ниже для публичных URL без данных трафика.

## Доказательства

- Граф `import`/`require`/dynamic import отметил `frontend/src/pages/web/Portfolio.js`, `Portfolio.css` и `frontend/src/hooks/useLenis.js` как недостижимые от приложения.
- `rg` подтвердил отсутствие потребителей `useLenis`, `Loader.css` и `web-vitals`, а также ограничил строки и селекторы Portfolio отключённым кластером.
- `npm run test:ci` прошёл: 2 набора, 15 тестов.
- `CI=true npm run build` завершился успешно; предупреждения относились к карте исходного кода транзитивного пакета и Browserslist, а не к найденным кандидатам.
- `npm ls web-vitals --depth=0` подтвердил `web-vitals@2.1.4` как прямую зависимость.

## Ограничения

- Клон неглубокий; история удаления или отключения Portfolio не использовалась как доказательство намерения.
- Внешняя телеметрия и трафик не проверялись, поэтому публичные URL нельзя объявить мёртвыми только по отсутствию внутренних ссылок.
- Для JavaScript/CRA-проекта не настроены Knip, ts-prune или TypeScript-проверка; вывод основан на графе импортов, поиске, тестах и production-сборке.
- Отсутствие проектного Guard-контекста нейтрально: оно не является находкой и не уменьшает оценку.
- Сопоставимого предыдущего результата не найдено; этот аудит становится базовой точкой для следующего сравнения.
