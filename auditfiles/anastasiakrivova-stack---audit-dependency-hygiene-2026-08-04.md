### Текущее состояние

Зависимости уже создают заметный риск для безопасных изменений. Основная причина — `react-scripts 5.0.1`, который используется в CI и публикационной сборке и удерживает множество проблемных вложенных пакетов.

Кроме того, приложение использует `react-router-dom 6.30.4` с исправлениями только в более новой основной версии. CI воспроизводим благодаря `npm ci`, но среда Netlify не закрепляет Node.js/npm; install scripts не ограничены, а пакеты сборки и тестов смешаны с runtime-зависимостями.

Сумма критериев — 21 из 45, то есть базовая оценка **47**. Прямые риски уменьшают ее на 11 пунктов: высокий приоритет — 8, средний — 3. Пробелы контроля уменьшают еще на 3 пункта: три находки среднего приоритета по 1; низкий приоритет не дает вычета. Применимый потолок 69 из-за незакрепленного основного пути публикационной сборки не меняет более низкий результат. Итог: `round(21 / 45 × 100) - 11 - 3 = 33`.

## Доказательства

- `frontend/package.json` содержит 17 прямых зависимостей и не содержит `devDependencies`, `packageManager` или `engines`.
- `frontend/package-lock.json` использует формат версии 3, фиксирует `react-router-dom 6.30.4` и содержит 1383 записи пакетов.
- `.github/workflows/ci.yml` закрепляет Node.js 24 и выполняет `npm ci`, тесты и сборку.
- `netlify.toml` запускает сборку из `frontend`, но не закрепляет версию Node.js/npm.
- Исходный код импортирует `BrowserRouter`, `Link` и `useNavigate` из `react-router-dom`.
- npm audit 11.16.0, OSV-Scanner 2.4.0 и Trivy 0.73.0 проверили текущий lockfile; результаты объединены в две корневые проблемы пакетов.

## Ограничения

- Пакеты не устанавливались и не обновлялись; сборка, тесты и package scripts не запускались.
- Достижимость проблемного кода внутри итогового браузерного bundle не доказана. Runtime-вывод для React Router основан на прямых импортах и области SPA.
- SBOM и образ контейнера отсутствуют; проверка образов неприменима к обнаруженной статической публикации.
- История Git неполная, поэтому скорость накопления долга во времени не оценивалась.
- Проектный Guard-контекст отсутствует; это нейтрально и не изменило область или оценку.
- Предыдущий сопоставимый аудит недоступен; этот результат становится базовой точкой для следующей проверки.
