## Незакрытые задачи

### 1. Форматтер

**Аудит:** tech-health TH-005 (частично).
**Почему не сделали:** Prettier перепишет почти каждый файл и утопит любой содержательный дифф.

Линтер вернули (шаг 13), форматтера нет. Если браться — **отдельным коммитом, который не содержит
ничего кроме форматирования**, иначе ревью невозможно.

### 2. Пять подавлений `react-hooks/exhaustive-deps`

**Аудит:** tech-health TH-005.

Аудит насчитал 13; восемь оказались мёртвыми и убраны на шаге 13. Осталось пять живых — в
`ChatWidget.jsx`, `serviceDemos/BotExample.jsx`, `BlackHole.jsx`, `Hub.jsx` (два). Правило стоит
предупреждением, чтобы они были видны.

⚠️ Каждое, скорее всего, осознанное: GSAP- и Three.js-таймлайны намеренно захватывают значения один
раз при монтировании. Снятие «на автомате» даёт бесконечные ре-рендеры.

### 3. Расширение e2e

Сценарий заявки на `/web` закрыт (шаг 16), но это один путь из нескольких. Не покрыты: чат-виджет
(`/.netlify/functions/lead`), модалка заявки на `/bots`, переключение EN/RU.

**С чего начать:** `frontend/e2e/enquiry.spec.js` — там уже есть заглушка Turnstile, приём
перехваченного payload и обход двух ловушек (см. ниже). Новый сценарий — рядом, тем же джобом.

⚠️ **Две ловушки, на которых первая версия падала — читать перед добавлением тестов:**

- **Lenis** доводит скролл на каждом кадре, элемент «плывёт», Playwright не кликает. Лечится
  `window.__lenis.stop()`, а не `force: true`.
- **WebGL на раннере считается программно.** В полный размер клик занимает 10 секунд. Тесты, которым
  чёрная дыра не нужна, ужимают её холст до 2 px через `addInitScript`.

Локаторы кнопок — по `button[type="submit"]`, а не по тексту: текст меняется на «✓ Sent!», и локатор
по имени просто перестаёт совпадать, а тест молча досиживает до таймаута.

## Требует владельца

| Что | Подробности |
|---|---|
| **Домены Turnstile** | В списке разрешённых должны быть прод, домен превью Netlify и `localhost`. Незарегистрированный домен = токен не выдаётся = **403 на все формы**. Откат без деплоя: убрать `TURNSTILE_SECRET_KEY` из переменных Netlify |
| **Вторая обязательная проверка CI** | Джобов теперь два, но ruleset требует только `build` — значит красный `e2e` merge не остановит. Включить: **Settings → Rules → Rulesets** → правило на `main` → **Require status checks to pass** → **Add checks** → `e2e`. ⚠️ Джоб должен отработать хотя бы раз, иначе его не будет в списке; вписывать имя руками нельзя — опечатка блокирует ветку навсегда. Подробности — `audit-fixes/04-ci-gate.md` |
| «Кастомный AI-агент» ($2000) и «Кастомная автоматизация» ($1500–2000) | Один продукт или два — из кода не следует |
| Рабочие часы против обещания 24 часа | Заявка в пятницу вечером формально должна быть отвечена в субботу |
| Судьба `PROJECT.md` | Лежит в `.gitignore` как внутренний, местами устарел (описывает удалённый `/backend`). Рекомендация — оставить как есть |

## Чего делать не надо

- **Менять цены и срок ответа.** Живут в `src/shared/pricing.js`, значения выбрал владелец.
  `pricing.test.js` уронит сборку, если цена окажется вписана в любой файл `src/` руками.
- **`npm audit fix --force`.** Оставшиеся два предупреждения — RSC-режим `react-router`, которого в
  проекте нет. Разбор в `frontend/DEPENDENCIES.md`.
- **Ослаблять защиту форм.** Honeypot, валидация, лимитер и Turnstile — результат аудита
  безопасности, см. `docs/adr/0002-public-endpoint-protection.md`.
- **Разводить `lang/en.js` и `lang/ru.js` по структуре.** Файлы обязаны совпадать ключ в ключ;
  `lang.test.js` это проверяет, потому что недостающий ключ — падение в рантайме, а не сборки.
- **Удалять «мёртвый» код по имени.** `t.demos.web.navLinks` содержит слово «Portfolio», но это
  контент макета внутри демо услуг. Проверять грепом с полными путями.
