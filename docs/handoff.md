**Почему не сделали:** находка свежая, а удаление требует проверки глазами на всех маршрутах.

Knip чист, но он **не читает CSS**. Классов, объявленных в `.css` и не встречающихся ни в одном
`.js`/`.jsx`: `Hero.css` — 68 из 94, `Services.css` — 52 из 201, `About.css` — 27 из 55,
`App.css` — 3 из 7, `Hub.css` — 3 из 58.

Крупные куски проверены руками: кластеры `.holo-*` и `.sb-*` в `Hero.css` — остатки убранного
варианта героя; блок `.abt-seniors` / `.abt-staff-*` в `About.css`.

⚠️ `hub-card-bots`, `hub-card-web`, `hub-card-apps` в списке есть, но **удалять их вслепую нельзя**:
имена такой формы обычно собираются шаблоном. Проверять в браузере, а не грепом — это ровно та
ошибка, от которой предостерегает раздел «Чего делать не надо».

**Аудит:** tech-health TH-005 (частично).

### 4. Пять подавлений `react-hooks/exhaustive-deps`

**Аудит:** tech-health TH-005.

Аудит насчитал 13; восемь оказались мёртвыми и убраны на шаге 13. Осталось пять живых — в
`ChatWidget.jsx`, `serviceDemos/BotExample.jsx`, `BlackHole.jsx`, `Hub.jsx` (два). Правило стоит

раз при монтировании. Снятие «на автомате» даёт бесконечные ре-рендеры.

### 5. Расширение e2e

Сценарий заявки на `/web` закрыт (шаг 16), но это один путь из нескольких. Не покрыты: чат-виджет
(`/.netlify/functions/lead`), модалка заявки на `/bots`, переключение EN/RU.

**С чего начать:** `frontend/e2e/enquiry.spec.js` — там уже есть заглушка Turnstile, приём
перехваченного payload и обход двух ловушек (см. ниже). Новый сценарий — рядом, тем же джобом.

Сюда же по смыслу — обновление `@testing-library/user-event` 13 → 14 (шаг 17): в v14 API стал
асинхронным (`userEvent.setup()`, `await user.click()`). Механически, но трогает каждый модульный
тест, который что-то нажимает.

⚠️ **Две ловушки, на которых первая версия падала — читать перед добавлением тестов:**

- **Lenis** доводит скролл на каждом кадре, элемент «плывёт», Playwright не кликает. Лечится
  `window.__lenis.stop()`, а не `force: true`.
- **WebGL на раннере считается программно.** В полный размер клик занимает 10 секунд. Тесты, которым
  чёрная дыра не нужна, ужимают её холст до 2 px через `addInitScript`.

Локаторы кнопок — по `button[type="submit"]`, а не по тексту: текст меняется на «✓ Sent!», и локатор
по имени просто перестаёт совпадать, а тест молча досиживает до таймаута.

## Требует владельца

| Что | Подробности |
|---|---|
| **Формы не работают на deploy preview** | В виджете Turnstile прописаны `katodevv.com` и `localhost`. Домен превью Netlify — `deploy-preview-N--<site>.netlify.app` — под них не подпадает: Cloudflare покрывает домен и его поддомены, а превью это **сосед**, а не поддомен. Значит на превью токен не выдаётся и форма получает **403**. Покрыть можно только добавив `netlify.app` целиком, то есть разрешив свой sitekey любому сайту на Netlify. Решение за владельцем; пока не принято — пункт «проверено на deploy preview» в шаблоне PR для форм невыполним, проверять только локально через `netlify dev` и на проде |
| **Вторая обязательная проверка CI** | Джобов теперь два, но ruleset `protect-main` требует только `build` — значит красный `e2e` merge не остановит. Включить: **Settings → Rules → Rulesets** → `protect-main` → **Require status checks to pass** → **Add checks** → `e2e`. ⚠️ Вписывать имя руками нельзя — опечатка блокирует ветку навсегда. Подробности — `audit-fixes/04-ci-gate.md` |
| Судьба `PROJECT.md` | Лежит в `.gitignore` как внутренний, местами устарел (описывает удалённый `/backend`). Рекомендация — оставить как есть |

## Чего делать не надо

- **Менять цены и срок ответа.** Живут в `src/shared/pricing.js`, значения выбрал владелец.
  `pricing.test.js` уронит сборку, если цена окажется вписана в любой файл `src/` руками.
- **`npm audit fix --force`.** Предупреждений сейчас ноль (шаг 17). Если появятся — сначала читать
  `frontend/DEPENDENCIES.md`: `--force` откатывает пакеты на старые мажоры ради предупреждений,
  которые часто к проекту не относятся.
- **Ослаблять защиту форм.** Honeypot, валидация, лимитер и Turnstile — результат аудита
  безопасности, см. `docs/adr/0002-public-endpoint-protection.md`.
- **Разводить `lang/en.js` и `lang/ru.js` по структуре.** Файлы обязаны совпадать ключ в ключ;
  `lang.test.js` это проверяет, потому что недостающий ключ — падение в рантайме, а не сборки.
- **Удалять «мёртвый» код по имени.** `t.demos.web.navLinks` содержит слово «Portfolio», но это
  контент макета внутри демо услуг. Проверять грепом с полными путями.
