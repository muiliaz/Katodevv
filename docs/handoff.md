## Требует владельца

| Что | Подробности |
|---|---|
| **Вторая обязательная проверка CI** | Ruleset `protect-main` требует только `build`, значит красный `e2e` merge не остановит. Включить: **Settings → Rules → Rulesets** → `protect-main` → **Require status checks to pass** → **Add checks** → `e2e`. ⚠️ Вписывать имя руками нельзя — опечатка блокирует ветку навсегда. Подробности — `audit-fixes/04-ci-gate.md` |
| **Формы не работают на deploy preview** | В виджете Turnstile прописаны `katodevv.com` и `localhost`. Cloudflare покрывает домен и его поддомены, а `deploy-preview-N--<site>.netlify.app` — сосед, а не поддомен, поэтому на превью токен не выдаётся и форма получает **403**. Покрыть можно только добавив `netlify.app` целиком, то есть разрешив свой sitekey любому сайту на Netlify. Пока решение не принято, формы проверять локально через `netlify dev` и на проде |
| Судьба `PROJECT.md` | Лежит в `.gitignore` как внутренний, местами устарел (описывает удалённый `/backend`). Рекомендация — оставить как есть |

## Чего делать не надо

- **Менять цены и срок ответа.** Живут в `src/shared/pricing.js`, значения выбрал владелец.
  `pricing.test.js` уронит сборку, если цена окажется вписана в любой файл `src/` руками.
- **`npm audit fix --force`.** Предупреждений сейчас ноль. Если появятся — сначала читать
  `frontend/DEPENDENCIES.md`: `--force` откатывает пакеты на старые мажоры ради предупреждений,
  которые часто к проекту не относятся. Прошлое закрылось само, без правок.
- **Ослаблять защиту форм.** Honeypot, валидация, лимитер и Turnstile — результат аудита
  безопасности, см. `docs/adr/0002-public-endpoint-protection.md`.
- **Разводить `lang/en.js` и `lang/ru.js` по структуре.** Файлы обязаны совпадать ключ в ключ;
  `lang.test.js` это проверяет, потому что недостающий ключ — падение в рантайме, а не сборки.
- **Смешивать форматирование с содержательной правкой.** Prettier настроен; если он что-то
  переформатировал — отдельным коммитом.
- **Удалять «мёртвый» код по имени.** `t.demos.web.navLinks` содержит слово «Portfolio», но это
  контент макета внутри демо услуг. Для CSS есть `npm run check:css` — он уже учитывает имена,
  собираемые шаблоном (`hub-card-${key}`), и не считает `www.w3.org` внутри data-URI за класс.
